# 白盒 · baihe.org

> 把每个原理拆到不能再拆。

一个开源的科学原理拆解站。百科给结论，教材给公式，短视频给三秒钟的震撼 —— 这里只做一件事：把一个原理**为什么必须如此**，一步一步讲清楚，直到你再也问不出"为什么"。

## 和别处有什么不一样

| | 百科 | 教材 | 短视频 | 白盒 |
|---|---|---|---|---|
| 给结论 | ✓ | ✓ | ✓ | ✓ |
| 给推导路径 | ✗ | 部分 | ✗ | ✓ |
| 建立直觉 | ✗ | 少 | ✓ | ✓ |
| 可亲手拨动变量 | ✗ | ✗ | ✗ | ✓ |
| 能提 PR 纠错 | 受限 | ✗ | ✗ | ✓ |

## 内容体系

**五个一级领域**：物理 / 数学 / 计算 / 哲学 / **横切原理**

其中「横切原理」不是学科，是视角 —— 熵、守恒、反馈、涌现、尺度、因果。它们不属于任何学科，却在所有学科里反复出现。这是本站最高价值的资产。

**三级结构**：领域 → 主题 → 文章

**难度分层**：`L1 直觉版`（无公式）/ `L2 标准版`（少量公式，逐项解释）/ `L3 推导版`（完整推导链）

## 每篇文章的固定六段

| 段落 | 作用 | 可缺省 |
|---|---|---|
| 一句话结论 | 首屏给确定性 | 否 |
| 直觉铺垫 | 用日常经验建立心智模型 | 否 |
| 推导过程 | 从直觉走向严谨 | L1 可省 |
| **交互演示** | 读者拨动变量，亲眼看到结论成立 | 至少 1 处 |
| 常见误解 | 主动排雷 | 否 |
| 延伸引用 | 指向下一条原理 | 否 |

## 本地运行

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # 输出到 dist/
```

## 写一篇新文章

1. 复制 `src/content/articles/hash.mdx`，重命名为你的主题；
2. 改 frontmatter（`title` / `domain` / `topic` / `level` / `summary` / `pubDate`）；
3. 按六段式填 `##` 标题，正文直接写 Markdown；
4. 需要交互演示时，从 `src/components/interactive/` 里 import 组件，用 `<MyDemo client:load />` 插入。**能复用就别新建**，确需新建的请抽象成通用组件放进这个目录；
5. 数学公式用 `$...$` 与 `$$...$$`，KaTeX 会自动渲染。

不需要改任何代码，也不需要改配置 —— 新文件放进去，页面自动出现。

## 目录结构

```
src/
├─ content/articles/    文章（.mdx，本站的全部内容）
├─ components/interactive/  可复用交互组件（React）
├─ layouts/             页面骨架与文章模板
├─ pages/               首页 / 领域页 / 文章页
├─ data/domains.js      领域与难度定义
├─ lib/                 纯算法（如 sha256.js）
└─ styles/global.css    设计系统
```

## 技术栈

Astro + React 岛屿 + MDX + KaTeX。内容站默认零 JavaScript，只在有交互演示的地方按需加载组件。

部署建议：Cloudflare Pages 或 GitHub Pages。（国内访问 Vercel 不稳定，不推荐。）
